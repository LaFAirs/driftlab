# Decisions

Decisions taken while building v0.1.0 (the brief asked for these to be recorded rather than discussed).

| # | Decision | Reason |
|---|---|---|
| 1 | **MIT licence.** The reference project dualshock-tools is MIT (checked through the GitHub licence API); Linux kernel drivers (GPL-2.0) were used for documentation only, no code copied. | Compatible; no change of licence needed. |
| 2 | **Procedural models instead of Blender/glTF.** Parts are generated in Rust (`driftlab-render`). | Reproducible without external tools, no binary assets, original designs by construction. A `.glb` loader can be added later. |
| 3 | **Offscreen renderer shown as an egui image** instead of a paint callback. | Independent of egui's pass/MSAA/depth configuration; needs no changes when eframe changes. |
| 4 | **Native window frame** (no custom title bar). | Reliable snapping, accessibility and HiDPI behaviour on all three platforms. |
| 5 | **Xbox and generic pads through `gilrs`** instead of calling XInput directly. | `gilrs` already wraps XInput/WGI on Windows and evdev/IOKit elsewhere; fewer unsafe FFI paths. |
| 6 | **System-wide virtual controller is not shipped in v0.1.0.** Steam Input profile export + instructions instead. | Windows: ViGEmBus is retired/unmaintained and no clean replacement exists. Linux: a `uinput` writer is planned but cannot be validated in CI on every distribution. macOS: no maintained option. The README and the UI say so. |
| 7 | **Firmware "known" = firmware version could be read and parsed.** Unknown/unreadable firmware blocks writes unless expert mode is on. | No authoritative public list of safe firmware versions exists. |
| 8 | **DS4 restore unsupported, DualSense restore via stick finetune.** | The DS4 protocol offers no read of the stick finetune data. |
| 9 | **Inno Setup for the Windows installer.** | Preinstalled on GitHub runners, in-place upgrades through a fixed `AppId`, multi-language wizard, simpler than WiX. |
| 10 | **AppImage built with `appimagetool` around the plain binary** (no bundled libraries). | wgpu/Vulkan must use the host's GPU drivers; bundling them breaks more systems than it helps. |
| 11 | **Fonts and icons**: Inter (SIL OFL 1.1) vendored from the Avalonia Inter package; Phosphor icons through `egui-pop-phosphor` (MIT). | Free licences, embedded, no network access at runtime. |
| 12 | **Update check uses the GitHub releases API on demand only**; opens the release page. | Brief: no silent auto-update. |
| 13 | **Screenshots are generated by the app itself** (`driftlab --screenshots <dir>`, demo mode) and committed. | Reproducible; CI runners have no GPU/display. |
| 14 | **Binaries are unsigned unless signing secrets are configured.** | No certificates available; steps are wired up and skipped without secrets. |
